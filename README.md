# StudyMate AI

An AI-powered study assistant built with Python, Streamlit, and the Gemini API.

## Features

- Summarize study notes
- Generate quizzes and flashcards
- Improve written answers
- Explain concepts in simple language
- Solve Maths and Science problems step by step
- Create study plans
- Add notes using voice input or upload a PDF
- Download generated answers as PDFs

## Run locally

1. Install the packages listed in `requirements.txt`.
2. Create a `.env` file in the project folder and add your Gemini API key:

   `GEMINI_API_KEY=your_api_key_here`

3. Start the app:

   `streamlit run app.py`

Keep your real API key private. Never upload your `.env` file to GitHub.
