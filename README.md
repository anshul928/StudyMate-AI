# StudyMate AI

An AI-powered study assistant built with Python and Streamlit.

## Features

- Summarize study notes
- Generate quiz questions
- Improve written answers
- Explain concepts in simple language

## Project files

- `app.py` — Main application
- `requirements.txt` — Required Python packages
- `.env` — Stores the OpenAI API key locally. Keep this file private.

## Setup

When Python and internet are available:

1. Install the packages listed in `requirements.txt`.
2. Add your OpenAI API key to the `.env` file.
3. Open a terminal in the project folder and run:

   `streamlit run app.py`
